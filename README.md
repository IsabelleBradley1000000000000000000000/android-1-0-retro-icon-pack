# Android 1.0 Retro Icon Pack

A CandyBar icon pack featuring classic Android 1.0 style glossy icons with retro bevel effects.

## Icons Included
- Spotify
- Instagram
- Discord
- TikTok

## Building the APK

### Prerequisites
- Android SDK installed
- Gradle 8.0 or higher
- Java 11 or higher

### Build Command

```bash
./gradlew assembleDebug
```

The APK will be generated at:
```
app/build/outputs/apk/debug/app-debug.apk
```

### On Termux

1. Clone the repository
2. Navigate to the project directory
3. Run: `bash ./gradlew assembleDebug`
4. Transfer the APK to your device

## Installation

1. Enable "Unknown Sources" in your device settings
2. Install the APK file
3. Open the app and set it as your icon pack in your launcher
